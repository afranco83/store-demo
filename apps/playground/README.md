# @store-demo/playground

Sandbox de exploración y prototipado — Next.js App Router vacío, sin contenido de negocio ni convenciones específicas que respetar. Se usa para probar una idea rápida (una API de React, un patrón de Next.js) sin tocar `apps/storefront`/`apps/admin`.

No forma parte de la demo pública ni de ningún flujo de usuario; no tiene tests ni objetivo de cobertura.

## Cómo arrancar

```bash
pnpm turbo dev --filter=@store-demo/playground
```
